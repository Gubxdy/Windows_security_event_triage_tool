GETTING STARTED

Export events from Windows

  1. Open Event Viewer on a Windows system you own or are authorised to investigate.
  2. Go to Windows Logs → Security.
  3. Use Filter Current Log to narrow the events you need.
  4. Choose Save All Events As… and select CSV if that option is available in your Windows version.
  5. Upload the saved CSV here. Version 1 does not read raw .evtx files.

If your Event Viewer does not offer a suitable CSV export, see README.md for an optional PowerShell export method.
